# auditredact

浏览器单页工作台（原生 ES 模块，零依赖）。

## 起服务看页面

    python3 -m http.server 8000

浏览器打开 http://127.0.0.1:8000/ ，改样例点运行看结果。

## 测试

    node tests/run.js

## 场景自检

    node check_sample.js

## 规则语义

- 前缀规则 `{"prefix": "tok_", "digits": 4}`：前缀之后恰好 `digits` 个 token 字符（`[0-9A-Za-z]`）且后接边界时，替换成等长掩码；各位全同的占位值（如 `9999`、`####`）跳过，因此已脱敏文本天然幂等。
- 邮箱规则 `{"kind": "mail", "local": 3}`：保留 local 前 3 位，其余替换成等长掩码；local 不够长则不动、不计命中。
- 白名单片段整体原样保留，与规则冲突时白名单优先（不做部分替换）。
- 规则缺前缀或必要字段抛 `E_BAD_RULE`，不做整体替换。
- 预算：白名单与规则各合并成单个正则各扫一遍，O(文本长度)，不按规则重扫全文。
- 顶层 `mask` 字段是各规则的默认掩码字符（默认 `#`），规则可自带 `mask` 覆盖。
